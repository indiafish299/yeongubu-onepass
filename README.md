# exam-tools — 선생님용 시험지 제작·검증 (Claude Code 플러그인)

| 스킬 | 하는 일 |
|---|---|
| `exam-setup` 처음 준비 | 파이썬·검증 코드·AI 명령줄 도구를 알아서 설치·업데이트하고, 로그인을 돕고, 선생님 요금제에서 실제로 되는 검토자 모델을 골라 둔다 |
| `exam-paper` 원안 제작 | 출제 설계 → 문항 → 학교 원안 양식(한글)에 조립(정답은 형광펜: 화면에만 보이고 인쇄 안 됨) → 정답·배점표, 이원목적분류표, 문항정보표 |
| `exam-verify` 시험지 검증 | 여러 AI 모델이 정답 없이 따로 풀고 흠잡기·범위·오탈자·반박 → 정답표 대조 → 「사람이 다시 볼 의심 목록」 보고서 |

## 설치 (선생님)

Claude Code(데스크톱 앱 또는 터미널)에서:

    /plugin marketplace add <이 저장소 주소 또는 폴더>
    /plugin install exam-tools@school-exam

그다음 「시험지 검증 준비해 줘」라고 하면 `exam-setup` 이 나머지를 합니다. 선생님이 하실 일은 브라우저에서 로그인하는 것뿐입니다.

## 요금제별 검토자

| 가진 요금제 | 검토자 |
|---|---|
| Claude 만 | Claude 모델 둘(서로 결과를 못 봄). 반박은 같은 회사 다른 모델 |
| Claude + ChatGPT 또는 Gemini | 셋 |
| 셋 다 | 넷 |

요금제가 낮아 최상위 모델이 안 되면 그 회사의 다음 모델로 자동으로 내려갑니다.

## 지켜지는 원칙

- 시험지·정답·보고서는 선생님 PC(`~/.exam-tools/work/`)에만 둡니다. 이 저장소에는 시험 내용을 넣지 않습니다(`.gitignore`).
- 다른 회사 AI 로 시험지를 보내기 전에 가린 이미지와 글자를 보여 드리고 확인받습니다(학교명·출제자·결재란은 자동으로 가림).
- 모델은 정답을 끝까지 보지 못합니다. 정답 대조는 스크립트가 합니다.
- 비밀번호를 대신 입력하지 않습니다. 보고서는 통과 도장이 아니고, 최종 판정은 선생님이 합니다.

## 개발

- 검증 코드: `plugins/exam-tools/skills/exam-verify/engine/` (`exam_verify/cli.py`)
- 가짜 시험지로 처음부터 끝까지: 윈도우 `engine/tests/run_fake.ps1`, 맥 `engine/tests/run_fake.sh`
- 집 폴더를 바꿔 새 PC 처럼 시험: `EXAM_TOOLS_HOME=<임시 폴더>`
