# 연구부 원패스 — 1분 소개 영상 대본 (클로드 모션용)

claude.ai 의 클로드 모션에 아래 「붙여 넣을 글」을 그대로 넣으면 됩니다. 만든 MP4 는 안내 페이지와 연수 자료에 씁니다.
시험 내용(실제 문항·정답·학교명)은 넣지 않습니다. 화면 속 시험지는 모두 가짜 예시입니다.

## 붙여 넣을 글

1분 길이의 세로가 아닌 가로(16:9) 모션 그래픽 소개 영상을 만들어 줘. 대상은 컴퓨터와 인공지능이 서툰 중·고등학교 선생님이다.
제목은 「연구부 원패스」. 말투는 차분하고 친절하게, 화면 글자는 크고 짧게(한 화면 15자 안팎). 배경은 미색 종이, 글자는 진한 남색, 강조는 노란 형광펜 줄.
형광펜이 글자 위를 쓱 긋는 움직임을 영상 전체의 반복 모티프로 써 줘. 실제 회사 로고나 실제 학교 이름은 쓰지 마.

장면:
1. (0~6초) 빈 시험지 한 장이 화면 가운데로 미끄러져 들어온다. 큰 글자: 「시험지 원안, 한 번에」. 형광펜이 「한 번에」를 긋는다.
2. (6~14초) 선생님이 말풍선으로 「기말고사 원안 만들어 줘」라고 말한다. 시험지에 문항 줄이 차례로 채워지고, 정답 번호 ③에 형광펜이 그어진다. 자막: 「정답은 형광펜 — 종이 인쇄엔 안 나와요」.
3. (14~22초) 「옳지 않은 것은?」 문장에서 「않은」에만 밑줄과 굵게가 생긴다. 선지 두 줄 사이가 살짝 벌어진다. 자막: 「학교 양식 그대로, 보기 좋게」.
4. (22~34초) 시험지 옆에 AI 검토자 카드 네 장이 하나씩 나타난다(로봇 그림 대신 단순한 동그라미 얼굴). 각 카드에 연필이 움직이고 확인 표시가 생긴다. 자막: 「AI 여럿이 정답을 모른 채 직접 풀어 봐요」.
5. (34~44초) 두 카드가 서로 화살표로 「반박」을 주고받는다. 한 지적은 흐려지고(반박됨), 한 지적은 남는다. 자막: 「서로 따져 보고 남은 것만」.
6. (44~52초) 보고서 카드가 펼쳐진다. 맨 위 「한눈에」 세 줄, 그중 「꼭 다시 볼 문항: 7번」에 형광펜. 자막: 「다시 볼 문항만 쏙」.
7. (52~60초) 자물쇠 아이콘과 함께 자막: 「시험지는 내 컴퓨터에만」. 마지막 화면: 「연구부 원패스 — Claude에게 "원패스 준비해 줘"」.

음악은 잔잔한 피아노, 효과음은 형광펜 긋는 소리 정도만.

## 만든 뒤

- 영상이 나오면 안내 페이지(`docs/onepass-guide.html`)의 첫 그림 아래에 링크를 붙인다.
- 장면 2~6의 글자가 실제 기능과 맞는지(형광펜 정답, '않은' 밑줄+굵게, 정답 모른 채 풀기, 반박, 한눈에 요약, 로컬 보관) 한 번 확인한다.
