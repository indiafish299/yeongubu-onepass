연구부 원패스

시험지 원안을 만들고, 여러 AI가 직접 풀어 보며 검증하는 일까지 한 번에. 선생님은 Claude에게 말로 부탁만 하시면 됩니다.

① 원안에 정답 형광펜② AI 여럿이 따로 풀기③ 다시 볼 문항 보고서

선생님이 하실 일은 세 가지입니다

  1. Claude 앱을 설치하고 로그인합니다

    claude.ai/download에서 내 컴퓨터(윈도우·맥)용을 받아 설치합니다. Claude 유료 요금제(Pro 이상)가 필요합니다. 앱을 열고 왼쪽 위의 Code 탭을 누릅니다.

  2. 원패스를 넣습니다 (두 줄 붙여 넣기)

    Code 화면의 입력 칸에 아래 두 줄을 한 줄씩 붙여 넣고 Enter를 누릅니다.

    /plugin marketplace add indiafish299/yeongubu-onepass
    /plugin install onepass@yeongubu

    설치가 끝나면 앱을 한 번 닫았다 엽니다.

  3. 「원패스 준비해 줘」라고 말합니다

    필요한 프로그램은 Claude가 알아서 설치합니다. 브라우저 로그인 창이 뜨면 선생님 계정으로 로그인만 해 주세요(비밀번호는 Claude가 대신 넣지 않습니다). 2~5분 걸립니다.

그다음엔 이렇게 말하면 됩니다

원안 만들기「2학기 기말고사 원안 만들어 줘. 지난 원안 파일은 이거야.」
시험지 검증「이 원안 검증해 줘. 정답·배점표는 이 파일이야.」
고치기「10번 ㄷ 문장 자연스럽게 고쳐 줘. 정답은 그대로.」
확인「고친 쪽을 그림으로 보여 줘.」

무엇을 해 주나요

원안 만들기

출제 설계 → 문항 → 학교 원안 양식(한글)에 조립까지 합니다. 정답은 형광펜(종이 인쇄에는 안 나옴), 부정 발문은 「옳지 않은」, 선지 줄 간격은 본문과 비슷하게 맞춥니다. 정답·배점표, 이원목적분류표, 문항정보표도 만듭니다.

시험지 검증

여러 AI 모델이 정답을 모른 채 따로 풀고 흠을 찾습니다. 복수 정답, 조건 부족, 오탈자, 범위 밖을 서로 반박하게 한 뒤, 「꼭 다시 볼 문항」을 쉬운 말 보고서로 드립니다.

처음 준비

파이썬과 AI 도구를 알아서 설치하고, 선생님이 가진 AI 요금제에서 실제로 되는 모델을 골라 둡니다. 다음부터는 바로 쓰면 됩니다.

가진 AI 요금제에 맞춰 돌아갑니다

가진 요금제검토자믿을 만한 정도
Claude만Claude 모델 둘쓸 만함 (같은 회사끼리 반박)
Claude + ChatGPT 또는 Gemini셋좋음
셋 다넷가장 좋음

요금제가 낮아 최상위 모델이 안 되면 그 회사의 다음 모델로 자동으로 바꿉니다. 검증 전에 남은 사용량과 걸리는 시간(보통 30~60분)을 먼저 알려 드립니다.

안심하고 쓰세요

  • 시험지·정답·보고서는 선생님 컴퓨터에만 둡니다. 메신저나 공유 드라이브로 보내지 않습니다.
  • AI에게 보내기 전에 학교명·출제자·결재란을 자동으로 가리고, 가린 그림을 보여 드린 뒤 「보내도 됨」을 받습니다.
  • 정답표도 선생님이 눈으로 확인한 뒤에만 씁니다. AI는 끝까지 정답을 보지 못합니다.
  • 원본 파일은 덮어쓰지 않고, 고친 것은 새 이름으로 저장합니다.
  • 보고서는 통과 도장이 아닙니다. 최종 판단은 선생님과 교과 협의회가 합니다.

자주 묻는 질문

한글(한컴오피스)이 없어도 되나요?

검증은 한글에서 저장한 PDF만 있으면 됩니다. 원안을 한글 양식에 조립하는 것은 한글이 설치된 윈도우 PC에서 합니다.

맥에서도 되나요?

됩니다. 원안 조립만 한글이 있는 윈도우 PC가 필요합니다.

PDF로 저장하면 정답이 보여요.

형광펜은 종이로 인쇄하면 나오지 않지만 PDF로 저장하면 찍힙니다. 학생용 파일은 종이 인쇄로만 쓰세요.

중간에 멈췄어요.

「검증 이어서 해 줘」라고 말하면 빠진 부분만 이어서 돕니다. 로그인이 풀렸다면 로그인 창을 다시 띄워 드립니다.

설치가 안 돼요.

Claude에게 「원패스 준비가 안 돼」라고 말하면 무엇이 빠졌는지 점검하고 고칩니다.
