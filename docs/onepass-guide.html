연구부 원패스

만드신 원안을 여러 AI가 정답 없이 따로 풀고, 서로 반박하게 한 뒤 사람이 다시 볼 문항만 남깁니다. 원본·정답·보고서는 선생님 PC에만 둡니다.

  • 정답 비공개AI는 끝까지 정답을 못 봄
  • 교차 반박다른 회사 모델이 반박
  • 자동 가림학교·출제자·결재란
  • 관문 2개보내기·정답표는 사람이 확인
① 원안에 정답 형광펜② AI 여럿이 따로 풀기③ 다시 볼 문항 보고서
VERIFY · 검증 절차

정답을 숨긴 채, 여러 번 따져 봅니다

  1. 관문 1보내도 되는지 사람이 확인가린 쪽 이미지와 글자를 선생님이 보고 승인. 그림이 바뀌면 승인은 무효
  2. 1풀이모델마다 따로, 수험생처럼 끝까지 풀기. 서로의 답은 못 봄
  3. 2흠잡기복수 정답·정답 없음·조건 부족·두 가지로 읽히는 문장
  4. 3범위출제 범위·교과서 수준을 벗어난 문항
  5. 4교정글자 층을 한 글자씩 읽어 오탈자 찾기
  6. +양식AI 없이 스크립트가 문항 번호·ㄱㄴㄷ·(가)(나)(다) 순서, 선지 길이·수치 순서, 단 걸침, 선지 줄 간격, 배점 합을 확인
  7. 5반박지적마다 다른 회사 모델이 반박. 버틴 지적만 남김
  8. 관문 2정답표는 사람이 확인선생님이 확인한 정답표로 스크립트가 대조(모델에게는 주지 않음)
  9. 6보고서「꼭 다시 볼 문항」부터. 여러 모델이 함께 짚은 지적을 먼저
격리모델은 가린 쪽 이미지 폴더만 읽을 수 있습니다. 다른 파일·명령·웹을 쓰면 그 실행은 「격리 위반」으로 버립니다.
빠짐 표시모델 하나라도 빠지면 보고서 맨 위에 「검증 불완전」. 다시 돌리면 빠진 단계만 이어 갑니다.
고친 뒤엔 전체 재검증큰 오류가 같은 문항의 작은 흠을 가리기 때문에, 바뀐 문항만이 아니라 처음부터 다시 돌리고 지난 결과와 견줍니다.
요금제에 맞춘 검토자Claude만 있으면 2명, ChatGPT·Gemini가 있으면 3~4명. 회사가 다를수록 더 엄밀합니다.
SECURE · 시험지 보안

무엇이 PC에 남고, 무엇만 나가는지

보관시험지·정답·보고서는 선생님 PC(~/.exam-tools/work)에만. 메신저·공유 드라이브·메일로 보내지 않습니다.
가림AI로 보내기 전 머리 표·결재란·저작권 줄을 자동으로 찾아 가리고, 가린 뒤에도 남은 이름이 있으면 경고합니다.
확인보내기(관문 1)와 정답표(관문 2)는 선생님이 직접 확인해야만 다음 단계로 넘어갑니다.
원본원본 파일은 덮어쓰지 않고, 고친 것은 새 이름으로 저장합니다.
지우기선생님이 「지워」라고 할 때만, 결과와 AI 쪽 대화 기록까지 함께 지웁니다.
계정비밀번호는 Claude가 대신 넣지 않습니다. 로그인은 선생님이 브라우저에서 직접.

다른 회사 AI(ChatGPT·Gemini)를 쓰면 가린 쪽 이미지가 그 회사로 갑니다. 쓸지 말지는 처음 준비할 때 선생님이 정합니다.

본교 맞춤

본교 시험지 원안 양식에 그대로 맞췄습니다

일반 AI 도구는 아무 시험지 모양으로 만듭니다. 원패스는 본교 원안 양식을 기준으로, 만드는 것도 검증하는 것도 본교 원안에 맞춰 돌아갑니다. 따로 고칠 일이 거의 없습니다.

  1. 머리 표·결재란·배점안내지난 원안 파일을 그대로 틀로 써서 회차·날짜·교시만 바꿉니다.
  2. B4 2단, 문항이 단을 넘지 않게학교 글꼴·장평·자간과 어절 줄바꿈, 외톨이 줄·벌어진 줄을 자동으로 다듬습니다.
  3. 정답은 형광펜종이 인쇄에는 안 나와서 원안 한 부로 바로 제출할 수 있습니다.
  4. 「옳지 않은」'않은'에만 밑줄과 굵게.
  5. 선지 줄 간격①~⑤ 두 줄 선지를 본문 줄과 비슷하게(5.6mm) 넓힙니다.
  6. 면수·꼬리말·배점 합 100배점안내의 면수와 실제 면수, 총 문항 수가 맞는지 확인합니다.
검증도 본교 원안에 맞춰머리 표·결재란·저작권 줄을 자동으로 찾아 가리고, 형광펜 정답을 지운 뒤 AI에게 보냅니다. 본교 정답·배점표를 그대로 읽어 정답과 대조합니다.
제출 서류까지정답·배점표, 이원목적분류표, 나이스 문항정보표 입력용 표를 본교 양식으로 함께 만듭니다.

선생님이 하실 일은 세 가지입니다

  1. Claude 앱을 설치하고 로그인합니다

    claude.ai/download에서 내 컴퓨터(윈도우·맥)용을 받아 설치합니다. Claude 유료 요금제(Pro 이상)가 필요합니다. 앱을 열고 왼쪽 위의 Code 탭을 누릅니다.

  2. 아래 한 줄을 복사해 Claude에게 붙여 넣습니다

    Code 화면 입력 칸에 붙여 넣고 Enter. 나머지는 Claude가 알아서 설치합니다(윈도우·맥 모두, 1~5분). 「실행해도 될까요?」라고 물으면 허용을 누르세요.

    연구부 원패스 설치해 줘. 윈도우는 irm https://raw.githubusercontent.com/indiafish299/yeongubu-onepass/main/install.ps1 | iex , 맥은 curl -fsSL https://raw.githubusercontent.com/indiafish299/yeongubu-onepass/main/install.sh | bash 를 실행하면 돼.

  3. 앱을 다시 열고 「원패스 준비해 줘」라고 말합니다

    설치가 끝나면 Claude 앱을 껐다 켭니다. 「원패스 준비해 줘」라고 하면 쓰시는 AI를 확인하고 검토자를 골라 둡니다. 브라우저 로그인 창이 뜨면 선생님 계정으로 로그인만 해 주세요(비밀번호는 Claude가 대신 넣지 않습니다).

그다음엔 이렇게 말하면 됩니다

원안 만들기「2학기 기말고사 원안 만들어 줘. 지난 원안 파일은 이거야.」
시험지 검증「이 원안 검증해 줘. 정답·배점표는 이 파일이야.」
고치기「10번 ㄷ 문장 자연스럽게 고쳐 줘. 정답은 그대로.」
확인「고친 쪽을 그림으로 보여 줘.」

자주 묻는 질문

한글(한컴오피스)이 없어도 되나요?

검증은 한글에서 저장한 PDF만 있으면 됩니다. 한글이 없는 PC에서도 함께 깔리는 rhwp로 한글 파일의 글자와 쪽 모양을 읽을 수 있습니다. 원안을 한글 양식에 조립하는 것은 한글이 설치된 윈도우 PC에서 합니다.

무엇이 설치되나요?

Claude 명령줄 도구, 원패스 플러그인, 파이썬(uv)과 검증 코드, 한글 파일 읽기 도구 rhwp(공개 소프트웨어, MIT), 그리고 쓰시는 AI 요금제의 도구(ChatGPT → codex)입니다. 모두 공식 배포처에서 받고, rhwp는 정해 둔 판의 해시가 맞을 때만 설치합니다. 파이썬·검증 코드·rhwp는 선생님 폴더 ~/.exam-tools 한곳에 모아 둡니다.

맥에서도 되나요?

됩니다. 원안 조립만 한글이 있는 윈도우 PC가 필요합니다.

PDF로 저장하면 정답이 보여요.

형광펜은 종이로 인쇄하면 나오지 않지만 PDF로 저장하면 찍힙니다. 학생용 파일은 종이 인쇄로만 쓰세요.

중간에 멈췄어요.

「검증 이어서 해 줘」라고 말하면 빠진 부분만 이어서 돕니다. 로그인이 풀렸다면 로그인 창을 다시 띄워 드립니다.

설치가 안 돼요.

Claude에게 「원패스 준비가 안 돼」라고 말하면 무엇이 빠졌는지 점검하고 고칩니다. 설치 한 줄은 몇 번 다시 붙여 넣어도 괜찮습니다(이미 있는 것은 건너뛰고 최신으로 올립니다).

Claude 없이 직접 설치할 수도 있나요?

윈도우는 시작 메뉴에서 PowerShell을 열고 irm https://raw.githubusercontent.com/indiafish299/yeongubu-onepass/main/install.ps1 | iex, 맥은 터미널에서 curl -fsSL https://raw.githubusercontent.com/indiafish299/yeongubu-onepass/main/install.sh | bash를 붙여 넣으면 같은 설치가 됩니다.

새 기능이 나오면요?

설치 한 줄을 다시 붙여 넣으면 최신판으로 바뀝니다.
