# 연구부 원패스 — 원안 제작 (exam-paper)

선생님마다 학교·과목·양식·PC 환경이 다르다. **아무것도 가정하지 말고** 0단계에서 확인한 것만 쓴다.
진행 방식: 계획부터 세우고, 결정이 필요한 곳(❓)은 AskUserQuestion 선택지로 묻는다. 진행 기록은 선생님 저장 폴더의 `…원안_작업계획.md`에 단계별로 남긴다.

## 0. 시작 전 확인

### 0-1. PC 환경 — `~/.exam-tools/venv` 가 없으면 먼저 **exam-setup**(파이썬·패키지를 알아서 설치). 그다음 `scripts/check_env.ps1` 로 한글 자동화를 확인한다
| 결과 | 그에 따른 진행 |
|---|---|
| 한글(HWP) 자동화 없음 (Mac, 한글 미설치) | 문항·검증·정답표까지 하고, 원안은 HTML/PDF 초안으로 드림 → 한글 있는 PC에서 4단계. 지난 원안·학교 양식은 **rhwp**(exam-setup 이 깔아 둠)로 읽는다: `rhwp export-text`(글자), `rhwp export-png`(쪽 그림), `rhwp dump`(글꼴·문단 구조). 머리말 문구 바꾸기 정도는 `rhwp edit replace-text` 로 사본에 할 수 있지만, 조판(2단·자간·단 나눔)은 한글에서 한다 |
| Python 모듈 없음 | 설치는 선생님 동의 후 `pip install pywin32 pypdfium2 pillow matplotlib`, 또는 uv로 대체 |
| 브라우저 자동화 도구(ego-browser, Claude in Chrome 등) 없음 | 교과서 사이트 자료는 선생님이 직접 내려받아 폴더를 알려 주심 |
| 다른 AI 검토 도구(agy 등) | exam-verify에서 사용 여부 결정 |

### 0-2. 선생님 정보 ❓ — 처음 한 번 묻고 `exam_profile.md`(선생님 저장 폴더)에 적어 다음에 재사용
- 학교, 학년, 과목(과목코드), 시험(학기·회차), 시험 날짜·교시(모르면 "○월 ○일 ○교시"로 두고 나중에)
- **지난 원안 파일**(학교 양식의 기준) — 머리 표·결재란·배점안내·2단 구성을 그대로 쓴다
- 평가계획(출제 범위·문항 수·배점·서답형), 교과서(출판사·저자), 교과서 사이트 계정 여부
- 결과물 저장 폴더, 제출 형식(예: A4 단면 인쇄본, 제출 기한)

## 1. 출제 설계 ❓
- 출제 범위(평가계획 그대로?), 문항 수·형식, 배점 구성(합 100), 난이도 비율
- 수준: **교과서 수준**(본문·그림·탐구·단원 마무리 범위). 단원별 문항 수는 교과서 쪽수 비율로 제안
- 출제 방식: 처음부터 새로, 또는 학습지·형성평가 문항의 **변형 출제**(같은 개념·자료 유형, 수치·사례·선지 바꿈)
- 결과: `…출제 설계표.md` — 문항별 성취기준·평가 요소·교과서 쪽·난이도·배점·평가 범주(지식·이해/과정·기능/가치·태도), 정답 번호가 고르게 분포하도록

## 2. 교과서 자료 (출제 근거)
- 교과서 사이트(출판사별: 비바샘·티셀파 등)에서 교사용 교과서 PDF, 형성평가, 평가 문항 자료. **로그인은 선생님이 직접**(비밀번호를 대신 입력하지 않음)
- 받은 자료의 정답표·문항 오류부터 점검(`…원본 오류 점검표.md`) — 그대로 베끼면 오류도 따라온다
- 교과서 PDF 텍스트가 깨지면 페이지를 이미지로 렌더링해서 본다(`scripts/pdfrender.py`)
- (선택 ❓) 시험 전에 학생에게 나눠 줄 학습지를 만들지 — 만들면 받은 자료에서 문항을 골라 분량을 줄이고(학생 부담 고려), 교사용 정답·해설은 따로 만든다

## 3. 문항 작성
- 문항은 `items.py` 형식(`scripts/items_example.py`): 부정 발문은 `옳지 <u>않은</u>`(밑줄은 '않은'에만, 원안에서는 굵게도), 정답 1~5, 해설 포함
- 그림은 직접 그린다(`make_graph_example.py`) — 축·단위·구간 표시 명확히
- 용어·띄어쓰기는 **그 학교 교과서 표기**를 따른다
- 다 쓰면 **exam-verify**로 검증하고 선생님께 문항별 승인을 받는다

## 4. 원안 조립·편집 (한글)
1. **작업은 임시 작업 폴더에서**: 클라우드 동기화 폴더(구글드라이브 등)의 한글 파일을 자동화로 직접 열면 숨은 대화상자로 멈출 수 있다 → 사본으로 작업하고 결과만 저장 폴더로 복사. 경로는 백슬래시.
2. 작업 폴더에 `items.py`, `profile.json`(`scripts/profile_example.json` 복사), `template.hwp`(지난 원안 사본), 그림 파일
3. 지난 원안의 글꼴·장평·자간·줄 간격을 읽어 profile에 맞춘다: `<python> scripts/style_probe.py template.hwp out.txt 0 14`
   - `template_first_item_text` = 양식의 1번 문항 첫 문구(이 문구부터 끝까지 지우고 새 본문을 넣음)
   - `replace` = 머리말에서 바꿀 문구(회차, 날짜, 교시 등)
4. 실행: `powershell -ExecutionPolicy Bypass -File scripts/rebuild.ps1 -Work <작업폴더> -Ver v1` → `final_v1.hwp/.pdf`, `img_v1\*.png`
   - 하는 일: 어절 단위 줄 나눔, 학교 양식 글꼴·장평·자간, 머리 글자(번호·ㄱ.·(가)·①) 내어쓰기 정렬, 상자·표 여백, **PDF로 단어 간격을 재서 문단별 자간 조정**(벌어진 줄·외톨이 줄·혼자 남은 "[5점]"), 문항이 두 단에 걸치지 않게 단 나눔, 머리말 치환, 끝에 `CHECK` 목록 출력
   - 끝에 `markpen.py`가 정답 번호 표시를 **형광펜**(종이 인쇄에는 안 나옴, 단 PDF 로 저장하면 찍힘)으로 바꾸고, 부정 발문은 `않은`만 **밑줄+굵게**, 두 줄 선지(①~⑤ 2행×3열 표)의 줄 높이는 **5.6mm**(본문 한 줄과 비슷; 가져온 그대로는 4.1mm라 좁다는 지적, 2026-11-24)로 맞춘다. 글자 음영색·글자색으로 정답을 표시하면 인쇄본에 답이 나온다(2026-11-24 선생님 지적). 예전 원안 파일도 `<python> scripts/markpen.py 원본.hwp 새이름.hwp`로 고칠 수 있다(원본은 덮어쓰지 않는다)
   - 꼬리말 총 쪽수 "(4)"가 바뀌면 `scripts/fix_footer.py`
5. **캡처 검사(필수)**: `img_vN\*.png`와 PDF 렌더를 **면마다 직접 본다** — 단어 중간 끊김, 외톨이 줄, 상자 테두리에 붙은 글자, 내어쓰기, 표 칸 여백, 그림, 정답 표시 방식(학교 양식대로), 머리말 날짜·교시, 면수가 배점안내와 일치하는지
6. 자간으로 못 고친 `CHECK` 항목은 문장을 줄이는 안을 만들어 ❓ (승인받은 문항 문장은 임의로 고치지 않는다)
7. 고친 뒤 본문 글자가 빠지거나 바뀌지 않았는지 이전 PDF와 비교

학교 양식이 크게 다르면(1단, 다른 머리 표 등) `assemble.py` 설정을 그 양식에 맞춰 조정한다. 함정과 해결: `references/hwp-notes.md`

## 5. 제출 서류
- 정답·배점표(md), 이원목적분류표(`build_docs.py`로 HTML → 한글 → `polish_doc.py`), 문항정보표(나이스 입력용 md·csv — 입력은 선생님이 직접)
- 학교 양식·제출 규정이 다르면 그 학교 서식에 맞춘다(❓ 서식 파일 요청)
- 미리보기 PDF로 인쇄 상태 확인(원안이 B4여도 PDF가 A4로 나오면 A4 제출에 그대로 사용)
